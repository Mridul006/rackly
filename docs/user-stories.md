# Accounts
- As a new visitor, I can sign up as a renter or a provider so that I can use Rackly in the role I need.
- As a user, I can log in and log out so that only I can access my account.
- As an admin, I can remove fake or abusive GPU listings so that the marketplace stays trustworthy.

# Provider side
- As a provider, I can add a GPU listing with its type, price per hour and number of units so that renters can find it.
- As a provider, I can set the dates and hours when each GPU is available so that it is only booked when I'm ready to share it.
- As a provider, I can see how many units of each of my GPUs are free right now so that I know my current capacity.
- As a provider, I can see which of my GPUs are currently rented, and until when, so that I can plan around them.
- As a provider, I can see how much I've earned from each GPU so that I know whether listing it is worth it.

# Renter side
- As a renter, I can search and filter GPUs by price, GPU type and number of GPUs so that I can find what fits my workload and budget.
- As a renter, I can book a GPU for a start and end time, from hours up to years, so that I have it exactly when I need it.
- As a renter, I can see all my bookings (upcoming, active and past) so that I can keep track of what I've rented.
- As a renter, I can cancel a booking before it starts so that I get my money back if my plans change.
- As a renter, I can report a problem with a GPU I'm renting so that the provider and admin know about it.

# Money
- As a user, I can see my wallet balance and add money to it so that I can pay for bookings.
- As a renter, I am charged automatically when I make a booking so that payment is quick.
- As a user, I can see my history of bookings and payments so that I can check what I spent or earned.

# 3D view
- As a renter, I can see a 3D datacenter on the main page where each GPU shows its status so that I can see what's available at a glance.
- As a renter, I can click a GPU in the 3D view to see its details and book it so that browsing and booking happen in one place.

# Design notes
- The login page should have a 3D visual theme with a polished look.
